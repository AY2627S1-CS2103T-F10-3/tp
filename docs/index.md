**EduReg is a desktop application optimised for managing student details in a small tuition centre.**
It centralizes student-parent relationships, class rosters, fee payments, and educational records into a unified CLI
tool, enabling tuition centre admins to update enrollments, log attendance, and track assignment submissions
significantly faster than multi-step GUI systems.

* If you are interested in using EduReg, head over to the [_Quick Start_ section of the **User
  Guide**](UserGuide.html#quick-start).
* If you are interested in developing EduReg, the [**Developer Guide**](DeveloperGuide.html) is a good place to
  start.
